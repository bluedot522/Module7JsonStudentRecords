# Module7JsonStudentRecords
## Purpose
The purpose of this application is to add and display a table of student information, including student ID numbers, first and last names, programs, and GPAs. Once added, student information can be saved to a JSON file and reloaded.
## Adding a student
A student can be added by entering an ID number, first and last name, program, and GPA into the appropriate fields, then clicking the 'Add Student' button.
## Saving records
Records can be saved by clicking the 'Save to JSON' button.
## Loading records
Records can be loaded by clicking the 'Load from JSON' button.
## Clearing the display
The display can be cleared by clicking the 'Clear Display' button. This will remove information from the display, as well as any information previously entered in the program.
## Limitations
A few limitations include error messages being displayed one at a time. Only JSON files may be loaded and the file must be named "students.json". If any changes are made to the JSON file outside of the program, it will not reload until the 'Load from JSON' is clicked again.
